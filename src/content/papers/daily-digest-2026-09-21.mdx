### 3. Quokka swarm defensive optimization-based ensemble deep learning for disease prediction using remote monitoring data

- 来源：Computational biology and bioinformatics
- 发布：Sun, 20 Se
- 原文：[打开链接](<https://www.nature.com/articles/s41598-026-70049-9>)

# 论文总结：Quokka swarm defensive optimization-based ensemble deep learning for disease prediction using remote monitoring data

## 🎯 核心观点

1. **问题导向**：现有基于患者监测数据的疾病预测方法普遍存在泛化能力有限、对噪声或不完整生理信号鲁棒性不足的问题，难以满足及时临床干预的需求。

2. **方法创新**：本文提出了一种名为 **QSDO_Ensemble DL** 的新方法，将异常检测、肺动脉压（PAP）预测与集成深度学习相结合，并首次引入 **Quokka 群防御优化算法（QSDO）** 来调优集成模型的超参数。QSDO 融合了 Quokka 群优化（QSO）与攻防优化（ODO）两种机制。

3. **性能优越**：在 MIMIC-II 数据库上的实验表明，该方法实现了 **96.90% 的准确率、95.87% 的真阳性率（TPR）和 7.22% 的假阳性率（FPR）**，证明其能从生理监测信号中提供稳健、可靠的疾病预测。

## 📊 主要论据

1. **多阶段融合架构**：方法首先利用加权平均法对 II、III、AVL、AVF 导联及动脉血压（ABP）等生理信号进行异常检测；同时通过 **自适应混合注意力网络（AHANet）** 预测肺动脉压（PAP）。随后将异常检测与 PAP 预测的输出共同输入疾病检测系统，由 **ResNeXt、AHANet 和 Shuffle Attention Network（SA-Net）** 组成的集成深度学习分类器完成最终疾病预测。

2. **实验验证充分**：在 **MIMIC-II 数据库**上完成了模型训练与评估，量化结果（Accuracy 96.90%、TPR 95.87%、FPR 7.22%）直接支撑了方法在噪声和不完整信号条件下的鲁棒性与可靠性优势。

## 💡 对从业者的启示

在构建基于远程监测生理信号的疾病预测系统时，**单一模型往往难以兼顾泛化性与抗噪性**。本文的实践表明，将**异常检测与关键生理指标预测作为前置模块**、再通过**集成深度学习分类器**进行决策融合，并借助**仿生群智能优化算法（如 QSDO）自动调参**，是一条有效提升预测精度与鲁棒性的技术路径，尤其适用于 ICU 等场景下的多导联生理信号分析。

## 📌 一句话总结

本文提出 QSDO_Ensemble DL——一种融合异常检测、肺动脉压预测与 Quokka 群防御优化调参的集成深度学习框架，在 MIMIC-II 数据上实现了高准确率、高灵敏度和低假阳性率的鲁棒疾病预测。
